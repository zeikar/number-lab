Number Lab

Small machines for famous number facts. Each one does the arithmetic live in your browser, so you can poke at it, break it, and watch it work.

  • 6174

    Kaprekar's constant

    Sort, subtract, repeat. Unless its digits are all the same, every four-digit number lands on 6174 within seven rounds. Watch all 10,000 run at once.

Most of these started as a Numberphile video. Each machine links the one it came from.
